# תקין – דיווח מפגעים לעירייה

קוד אחד, שתי אפליקציות:

| אפליקציה | כתובת | לאן נשלח הדיווח | מה התושב מקבל |
|---|---|---|---|
| **תקין עירוני** | https://krmy1979.github.io/takin/ | למסך המוקדנים (`moked-ashkelon/admin.html`) | כניסה עם Google, מעקב סטטוס (התקבל / בטיפול / טופל), תשובות מהמוקד, מפת מפגעים בעיר |
| **תקין 106** | https://krmy1979.github.io/takin/106/ | בוואטסאפ למוקד 106 של העיר שנבחרה | בלי הרשמה ובלי שרת. מתאים לכל עיר. הדיווחים נשמרים רק בטלפון |

## הקבצים

- `index.html` – כל האפליקציה (מסכים, עיצוב וקוד). האפליקציה מזהה לפי הכתובת איזו גרסה היא (`/106/` = תקין 106).
- `sw.js` – מאפשר עבודה בלי אינטרנט והתקנה כאפליקציה.
- `manifest.webmanifest` – שם, צבעים ואייקון במסך הבית.
- `icon.svg`, `icon-192.png`, `icon-512.png` – אייקונים.
- `build-106.py` – בונה את התיקייה `106/` מהקבצים הראשיים.
- `106/` – תקין 106. **לא עורכים כאן ידנית** – אחרי כל שינוי ב-`index.html` מריצים `python3 build-106.py`.
